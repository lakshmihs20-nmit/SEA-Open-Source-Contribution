1. Introduction

Open-source software engineering is the process of developing software whose source code is publicly available. Developers can use, modify, and contribute to the project.

GitHub is a platform that allows developers to collaborate and contribute to open-source projects.

2. Problem Analysis

A Library Management System hosted on GitHub does not have proper documentation explaining how users can issue and return books.

This creates difficulties for users because they cannot understand the correct procedures. Therefore, the documentation needs to be improved.

3. Proposed Solution

The student can contribute to the project by following these steps:

1. Fork the Repository: Create a copy of the original Library Management System repository in the student's GitHub account.

2. Clone the Repository: Download the forked repository to the local computer.

3. Create Documentation: Create or modify a README.md file explaining the procedures for issuing and returning books.

4. Commit Changes: Save the changes with a meaningful commit message.

5. Submit Pull Request: Submit a Pull Request to the original repository requesting the project owner to accept the changes.

6. Review and Merge: The project owner checks the documentation and merges the contribution if it is correct.

4. Benefits of Open-Source Contribution

- Improves software documentation.
- Encourages teamwork and collaboration.
- Helps students gain practical experience.
- Improves software quality.
- Allows developers to share knowledge.

5. Challenges

- Understanding an existing project may be difficult.
- Incorrect documentation may create confusion.
- Pull Requests may require modifications before approval.

6. GitHub Contribution Workflow

Fork Repository
↓

↓
Create or Modify Documentation
↓

7. Conclusion

Open-source software engineering encourages developers to work together and improve existing software. By contributing proper documentation to the Library Management System, the student improves usability and gains practical experience in collaborative software development.
