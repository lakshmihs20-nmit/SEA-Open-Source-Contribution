### 2. Introduction

Mobile and web applications play an important role in making everyday activities easier and faster.

A mobile application runs on smartphones, whereas a web application can be accessed through a web browser. A Progressive Web Application (PWA) combines features of both mobile and web applications.

An Online Canteen Food Ordering System allows students to view food menus, place orders, make online payments, and receive notifications when their orders are ready.

This system reduces waiting time and makes canteen operations more efficient.

### 3. Problem Analysis

In a traditional college canteen, students have to stand in queues to check the menu, place orders, and collect their food.

This creates several problems:

1. Long waiting queues during lunch breaks.
2. Difficulty in checking available food items.
3. Time wasted while placing and collecting orders.
4. Manual order management can lead to mistakes.
5. Difficulty in managing multiple orders during peak hours.

Therefore, the college needs an online food ordering system that makes the ordering process faster and more convenient.

### 4. Proposed Solution

The proposed solution is to develop a **Progressive Web Application (PWA)** for the college canteen.

A PWA is suitable because it combines the accessibility of a website with features of a mobile application. Students can access it through their mobile browsers and can also add it to their home screens without installing it from an app store.

#### A. Comparison of Mobile, Web and PWA Applications

| Feature | Mobile Application | Web Application | PWA |
|---|---|---|---|
| Installation | Required | Not required | Optional |
| Accessibility | Through mobile devices | Through browsers | Through browsers |
| Updates | App updates required | Server-side updates | Server-side updates |
| Offline Support | Possible | Limited | Supported through caching |
| Development Cost | Generally higher | Moderate | Moderate |
| User Experience | Good | Good | App-like experience |

**Selection: Progressive Web Application (PWA)**

A PWA is selected because:

- Students can access it using a browser.
- No compulsory app installation is required.
- It provides an app-like experience.
- It supports notifications on compatible devices and browsers.
- It is easier to maintain because updates can be deployed centrally.

#### B. Major Functionalities

The system will provide the following functionalities:

**1. User Registration and Login**

Students can register and log in using their college email ID or student credentials.

**2. Menu Display**

Students can view available food items, prices, descriptions and availability.

**3. Online Food Ordering**

Students can select food items, add them to their cart, and place orders.

**4. Online Payment**

The system allows students to make payments using UPI, debit cards or other supported payment methods.

**5. Order Tracking and Notifications**

Students can track their order status, such as:
- Order Placed
- Order Accepted
- Preparing
- Ready for Pickup

Students receive notifications when their orders are ready.

### 5. Benefits and Challenges

#### A. Benefits

1. **Saves Time:** Students can order food without standing in long queues.
2. **Easy Accessibility:** Students can access the application using smartphones, tablets or computers.
3. **Better Order Management:** Canteen staff can manage incoming orders more efficiently.

#### B. Development Challenges

1. **Internet Connectivity:** Students need an internet connection for placing orders and processing online payments. Poor connectivity may affect the ordering process.

2. **Payment Security:** The application must protect students' payment information and ensure secure online transactions.

3. **Real-Time Order Management:** The system must update food availability and order status accurately to avoid accepting unavailable items or delaying notifications.

### 6. Conclusion

The Online Canteen Food Ordering System using a Progressive Web Application is an effective solution for improving the traditional college canteen experience.

It allows students to browse menus, place orders, make payments and receive notifications conveniently.

By reducing waiting time, improving order management and providing easy accessibility, the proposed system makes canteen operations faster and more efficient.

Therefore, implementing a PWA-based food ordering system can improve the overall experience for both students and canteen staff.
