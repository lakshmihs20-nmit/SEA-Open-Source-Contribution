# Waterfall Model

## Introduction
The Waterfall Model is a sequential
software development model.

## Phases
1. Requirement Analysis
2. System Design
3. Implementation
4. Testing
5. Deployment
6. Maintenance

## Example
A college library management system
with fixed requirements.

## Advantages
- Simple to understand
- Easy to manage

## Disadvantages
- Difficult to accommodate changes
- Testing occurs after implementation
