Question 2: Mobile and Web Applications Engineering

Online Canteen Food-Ordering System

1. Introduction to Mobile and Web Applications

Mobile applications are applications developed specifically for smartphones and tablets. They are installed on devices and can use features such as cameras, GPS and push notifications.

Web applications are applications accessed through internet browsers. They do not require installation and can be used on different devices.

Progressive Web Applications (PWAs) are web applications that provide an app-like experience. They can be added to the home screen, support notifications and offer certain offline features.

2. Comparison of Mobile, Web and PWA

Parameters	Mobile Application	Web Application	PWA
Access	Installed on device	Through web browser	Browser or home screen
Installation	Mandatory	Not required	Optional
Platform	Android/iOS	Multiple platforms	Multiple platforms
Notifications	Fully supported	Browser-dependent	Supported on compatible devices
Offline access	Can support offline mode	Generally limited	Supports selected offline features
Development	More expensive	Comparatively cheaper	Cost-effective
Updates	Through app updates	Automatically updated	Automatically updated

3. Selection of Suitable Application

For the college canteen food-ordering system, a Progressive Web Application (PWA) is the best suitable option.

Reasons for selecting PWA

* Easy Accessibility: Students can access the application using a browser without installing it.
* Cost Effective: A single application can be developed for multiple platforms.
* Push Notifications: Students can receive alerts when their food is ready.
* User Friendly: It provides an application-like interface and can be added to the home screen.
* Easy Maintenance: Updates can be made centrally without requiring students to manually update an installed app.

Thus, a PWA is a practical and economical solution for a college canteen.

4. Four Major Functionalities

1. User Registration and Login

* Students can create accounts using their college email ID or student credentials.
* Existing users can log in securely.
* User details can be stored in a database.

2. Food Menu and Cart Management

* Students can view the available food menu.
* Food items display their prices, descriptions and availability.
* Users can add items to their cart and modify quantities.
* The system automatically calculates the total amount.

3. Order Placement and Payment

* Students can confirm their selected food items.
* The system provides multiple payment options such as UPI, debit cards and net banking.
* An order confirmation is generated after successful payment.

4. Order Status and Notifications

* Students can view the current status of their orders.
* The system displays updates such as Order Placed, Preparing and Ready for Pickup.
* Push notifications alert students when their orders are ready for collection.

5. Three Major Development Challenges

1. Data Security and Privacy

Protecting student information, login credentials and payment details is important. Secure authentication and encrypted communication must be implemented.

2. Handling Multiple Orders

During lunch breaks, many students may place orders simultaneously. The system must process multiple requests efficiently without errors or order duplication.

3. Network Connectivity and Browser Compatibility

The application must function properly on different devices and browsers. Poor internet connectivity may affect payments, order updates and notifications.

7. Conclusion

The Progressive Web Application is an effective choice for developing an online canteen food-ordering system. It offers easy access, lower development costs and compatibility with different devices. Its features, including food selection, cart management, online payment and order notifications, help improve the overall canteen experience for students and reduce waiting time.
