Question 2: Mobile and Web Applications Engineering

Online Canteen Food-Ordering System 

1. Introduction to Mobile and Web Applications

Mobile applications are software programs designed to run on smartphones and tablets. They can be downloaded and installed from platforms such as Google Play Store and Apple App Store.
Ki
Web applications are software programs that run through web browsers such as Google Chrome, Safari and Firefox. Users can access them without installing any application.

Progressive Web Applications (PWAs) combine the features of mobile and web applications. They run through web browsers but can also be installed on devices and provide features such as notifications and offline access.

2. Comparison of Mobile, Web and Progressive Web Applications

Feature	Mobile Application	Web Application	PWA
Installation	Required	Not required	Optional
Accessibility	Through installed app	Through browser	Browser or home screen
Internet	Usually required	Required	Some features work offline
Notifications	Supported	Limited support depending on browser	Supported on compatible devices
Development cost	Higher	Moderate	Moderate
Maintenance	Separate app updates	Centralized updates	Centralized updates

3. Selection of Suitable Application Type

For the online canteen food-ordering system, a Progressive Web Application (PWA) would be the most suitable choice.

Justification:

* Students can access the system directly through their mobile browsers without downloading an application.
* It can be installed on the home screen like a normal mobile application.
* It supports push notifications to inform students when their orders are ready, on compatible browsers and devices.
* It is cost-effective because a single application can work across different devices and platforms.
* It allows centralized maintenance and updates.
* It can provide limited offline functionality, such as displaying previously loaded menu information.

Therefore, a PWA provides a balance between accessibility, cost, convenience and functionality.

4. Four Major Functionalities

1. Menu Browsing

* Students can view available food items.
* Each item displays its name, price and description.
* Food items can be categorized into snacks, meals, beverages, etc.
* Students can check item availability.

2. Order Placement

* Students can select food items and add them to the cart.
* They can increase or decrease quantities.
* The system calculates the total bill.
* Students can confirm and place their orders.

3. Online Payment

* Students can pay using UPI, debit cards, credit cards or other digital payment methods.
* The system verifies payment status.
* A payment confirmation is displayed after successful payment.

4. Order Tracking and Notifications

* Students can track their order status.
* Notifications are sent when the order is confirmed, prepared and ready for collection.
* Students can collect their food once the order is ready.

5. Three Major Development Challenges

1. Payment Security

The system must protect students’ payment information and ensure secure transactions. Payment gateways and encryption should be used to prevent unauthorized access and fraud.

2. Real-Time Order Management

The system must update order status immediately. Managing multiple orders simultaneously and avoiding duplicate orders can be challenging.

3. Cross-Platform Compatibility and Performance

The PWA should work smoothly on different smartphones, operating systems and browsers. It should provide a responsive interface and handle unstable internet connections efficiently.

7. Conclusion

A Progressive Web Application is the most suitable solution for the college online canteen food-ordering system. It provides the advantages of both mobile and web applications, allowing students to access the system easily without mandatory installation. Features such as menu browsing, online ordering, digital payments and real-time notifications make the food-ordering process faster, easier and more efficient.
