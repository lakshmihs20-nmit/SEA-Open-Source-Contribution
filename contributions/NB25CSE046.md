1. Introduction

Mobile and Web Applications are software applications designed to provide services to users through mobile devices and web browsers.

A mobile application is specifically developed for smartphones and tablets, whereas a web application runs through a web browser and can be accessed from different devices.

A Progressive Web Application (PWA) combines features of both mobile and web applications. It can be accessed through a browser, installed on a device and provides an app-like experience.

For the proposed college canteen system, students need a convenient platform to browse food menus, place orders, make online payments and receive notifications when their orders are ready.

2. Comparison of Mobile, Web and PWA Approaches

A. Mobile Application

- Developed specifically for Android or iOS devices.
- Can access device features such as cameras and notifications.
- Provides a smooth and app-like user experience.
- Usually requires installation from an application store.
- Development and maintenance may be costly when supporting multiple platforms.

B. Web Application

- Accessed through a web browser.
- Does not require installation.
- Works across different devices and operating systems.
- Can be updated centrally by developers.
- Some device features and offline capabilities may be limited.

C. Progressive Web Application (PWA)

- Combines the advantages of mobile and web applications.
- Can be accessed through a browser and installed on a device.
- Supports push notifications where supported by the browser and device.
- Can provide limited offline functionality using service workers.
- Requires less installation effort and can work across multiple platforms.

3. Selection of Suitable Application Type

A Progressive Web Application (PWA) is the most suitable choice for the college canteen food-ordering system.

Justification

1. Easy Accessibility: Students can access the system using a browser without downloading an application from an app store.
2. Cross-Platform Support: It works on smartphones, tablets and computers.
3. App-Like Experience: Students can install the PWA on their home screen for quick access.
4. Push Notifications: Students can receive notifications when their food orders are ready, subject to browser and device support.
5. Cost-Effective Development: A single application can serve multiple platforms, reducing development and maintenance effort.

Therefore, a PWA provides a practical and cost-effective solution for the college canteen.

4. Major Functionalities

1. User Registration and Login

Students can create accounts and securely log in using their credentials. The system maintains individual user profiles and order histories.

2. Menu Browsing and Food Selection

Students can view the available food items, prices, descriptions and categories. They can select food items and add them to their shopping cart.

3. Order Placement and Online Payment

Students can review their cart, confirm their orders and make payments using supported online payment methods such as UPI, debit cards or net banking.

4. Order Tracking and Notifications

Students can track their order status, such as Placed, Preparing and Ready for Pickup. The system sends notifications when the order is ready for collection.

5. Development Challenges

1. Payment Security

The system must protect students' payment information and ensure secure transactions. Integration with a reliable payment gateway and secure communication is necessary.

2. Real-Time Order Management

The system must update order statuses accurately and notify students without unnecessary delays. Handling multiple orders simultaneously can also be challenging.

3. Internet Connectivity and Browser Compatibility

The application depends on internet connectivity for placing orders and processing payments. It must also work properly across different browsers, devices and screen sizes.

Workflow Explanation

1. The student opens the canteen PWA and logs in.
2. The student browses the menu and selects food items.
3. Selected items are added to the shopping cart.
4. The student confirms the order and makes payment.
5. After successful payment, the order is sent to the canteen.
6. The canteen prepares the food and updates the order status.
7. The system sends a notification when the order is ready.
8. The student collects the order from the canteen.

7. Conclusion

A Progressive Web Application is a suitable solution for developing an online canteen food-ordering system in a college.

It provides easy accessibility, cross-platform compatibility, an app-like experience and notification support. Students can conveniently browse menus, place orders, make payments and receive updates about their food orders.

Although payment security, real-time order management and internet connectivity are important challenges, they can be addressed through proper application design and reliable technologies.

Thus, implementing a PWA can improve the efficiency of college canteen operations and provide a better food-ordering experience for students.
